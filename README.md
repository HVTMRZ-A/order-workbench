# 订单工作台

用于 Windows 的便携订单流程跟进工具。当前版本 **v1.17.0**。

[下载最新版程序](https://github.com/HVTMRZ-A/order-workbench/releases/latest) · [详细使用说明](先看这里.txt) · [版本记录](CHANGELOG.md)

## 自动检测与软件内更新

本版在订单页面启动完成后后台检查更新，持续运行时每 4 小时检查。发现新版后侧栏显示提示；断网只显示轻提示并延迟重试。检测不弹窗、不下载也不安装，点击提示后仍由你决定是否更新。

已安装 v1.10 的用户，可直接用“软件更新”升级到本版。

旧版需要先手动安装一次 v1.10.0，保留原来的 `data`。以后点击左下角 **软件更新 → 下载并更新**，保存完成后会自动关闭、替换并重新打开。

更新从此公开仓库的正式 Releases 获取，无需登录；只替换程序组件，保留订单、备份与外部文件路径。下载和校验失败时继续使用原版，安装中途失败会恢复旧文件。请保留配套的 `订单更新助手.exe`。

- 沿用本机账户和本地数据；已有订单、历史、外观和外部依据路径直接保留。

## 可以做什么

- 多订单同时跟进，按订单折叠查看总进度，展开查看各机型。
- 跟踪机器外形与状态、采购交接、丝印、铭牌、说明书、纸箱、二厂网版和计划交接。
- 拖入 `.xlsx` 生产单，核对合同、型号和数量；只勾选需要导入的产品，排除空白或无用行。
- 自动提取订单简称；机型资料保留原文件、工作表、行号与原始要求的来源信息。
- 整单批量确认，允许选择机型；再次打开显示已保存状态，部分确认显示数量，可继续办理。
- 依据文件可拖入或选择，整单一份文件能关联多个机型；只存原路径，不复制原文件。
- 显示最近保存时间和未保存状态；使用右上角关闭时提示保存。
- 数据写入程序旁的 `data` 目录，支持备份，更新时保留数据目录即可。

## 下载和使用

1. 在 **Releases** 下载 `order-workbench-v1.16.0-portable.zip`，解压完整目录。
2. 双击 `订单工作台.exe`。不要只拷贝一个 EXE，应保留配套组件和 `runtimes`。
3. 先使用示例模式熟悉流程，再创建或导入正式订单。

需要 .NET Framework 4.6.2 或更新版本，以及 Microsoft Edge WebView2 Runtime。

生产单导入后，各机型仍需逐项确认；录入资料本身不会自动确认流程或标记交接完成。
预览中取消某行的“是否导入”勾选，该行不会创建订单，也不会阻止其他行的必填校验。

## 更新与数据

先保存并完全退出旧版，将新版完整发行包解压到原目录并替换程序文件，**保留原来的 `data` 文件夹**。
不需要导出再导入；当前保持数据格式 `schema=1`。

`data/orders.json` 保存订单和关联记录，`data/backups` 保留最近 50 次旧版本。
源码仓库与发行包均不包含个人订单数据、客户生产单或依据文件。

依据文件只记录路径。移动文件、改名或换电脑后，需要保持原路径可访问，或在详情中重新关联。
复制应用与订单数据不会自动复制这些外部资料。

## 源码与编译

原生程序使用 C# WinForms、WebView2 与本地回环 HTTP 服务；界面为 HTML/CSS/JavaScript。

- `源码/Program.cs`：本机服务与订单持久化。
- `源码/WorkbenchWindow.cs`：原生窗口、保存状态与退出提醒。
- `源码/ProductionPreview.cs`、`源码/production*.js`：生产单解析与选择导入。
- `源码/batch*.js`：整单确认和保存状态恢复。
- `源码/evidence*.js`、`源码/EvidenceFiles.cs`：外部依据文件的路径关联。

发行包包含编译后的完整程序、WebView2 依赖和同版本源码。若从仓库编译，可先将同版本发行包解压到仓库目录，保留依赖文件，再运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\源码\编译.ps1
```

编译脚本使用系统 .NET Framework C# 编译器，不会迁移订单数据。编译前请退出正在运行的程序。
第三方组件声明见 [WebView2组件许可.txt](WebView2组件许可.txt)。本仓库未单独授予开源许可证。
