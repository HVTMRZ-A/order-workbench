订单工作台 v1.18.0 · 持续追踪版

这是原“订单工作台”（HVTMRZ-A/order-workbench）的后续版本。
正式版通过本项目 GitHub Releases 提供完整程序包。

新增“持续追踪”：
1. 左侧选择“持续追踪”，点击“新增事项”，内容全部由你填写。
2. 可选关联整单，也可以作为独立事项，不需填写负责人、交期或流程阶段。
3. 勾选即确认并保存；取消勾选则恢复待确认。支持编辑、删除、搜索和状态筛选。
4. 订单完成、归档后事项仍保留，追踪操作不改变原订单流程。
5. 栏目“修改记录”集中查看账户、时间、变更内容；相关订单的修改记录也有入口可查。
6. 编辑未保存时，原有右上角关闭保存提醒及 Ctrl+S 继续适用。
7. 完整 JSON 备份包含追踪事项及记录。旧备份缺少追踪字段时，导入不会清空已有事项。

安装与更新：
已有版本点击“软件更新 → 下载并更新”即可升级，原 data 数据保留。
先保存并退出原程序，将本包解压到原程序文件夹，覆盖程序文件，保留原 data 文件夹。
包中不含 data，不需要导出再导入原订单；原账户、订单、设置仍由原 data 读取。
如果在新文件夹独立使用，会使用新的空数据，不会自动读取另一目录的订单。

启动“订单工作台.exe”，保持 WebView2 DLL 与 runtimes 文件夹完整。
仍为本地版本，本次没有实施服务器或云端同步。
