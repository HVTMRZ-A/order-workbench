订单工作台 v1.16 · 整单料号与智能识别版

一、保留原数据升级
先保存并完全退出旧版，再把“订单工作台_v1.16_整单料号与智能识别升级包.zip”解压到原“订单工作台.exe”所在文件夹，替换程序文件。
保留原来的 data 文件夹。升级包不包含 data，无需导出、导入或迁移订单。
本版保持 schema=1，旧订单没有依据文件字段也可直接读取。

本版新增：整单填写料号和长文本识别
在整单确认中可直接填写各机型的机器、丝印、铭牌、说明书和纸箱料号，支持只保存料号。
可粘贴多行ERP文本，点击“识别并匹配型号”，核对机型与项目后点击“填入已选识别结果”，最后保存整单。
默认自动判断项目，也可指定项目。支持公司型号和客户型号，按完整型号匹配，不依赖行顺序。
未匹配、多候选、同机型不同料号和已有不同料号均提示人工核对，不直接覆盖；覆盖已有料号须明确确认。
单个料号格粘贴一行文本可自动提取料号；型号或项目不符时转到识别预览，多行文本也转到预览。
识别和填入仅修改本次草稿，保存后才落盘；取消不改订单，未选机型和不需要的包材不会被填写。
修改已交接的机器料号需重新核对采购和计划，修改包材料号需重新核对计划，可在本次整单一起确认。
缺料号仍按原机制提示风险，修改记录按当前登录账户记录料号前后值，可在每个订单的记录入口查看。
已有订单、账户、设置、历史记录和外部依据路径保持，不需要迁移数据。

上版修复：账户按钮先打开菜单
点击右上角账户只查看账户菜单，不会退出登录，也不要求重新输入账号密码。
菜单提供“切换账户”“添加账户”“退出登录”“退出程序”，点击关闭或按Esc返回。
选择“切换账户”后，验证新账号成功前保留原登录；取消或密码错误都不会强制退出原账户。
只有明确选择“退出登录”才会注销当前会话。退出后登录界面提供“退出程序”，无需重新登录才能退出。
修复登录时“账户姓名”栏仍显示的问题：只有创建新账户时才显示姓名栏。
切换、添加及退出登录前仍需保存或取消当前编辑，防止丢失修改。

本版新增：图标同步到整个程序
设置中切换图标时，界面、窗口标题栏、任务栏和托盘图标一起预览；取消会恢复原已保存图标。
保存后生成data/program-icon.ico，包含16、24、32、48、64、128、256像素的Windows图标。
内置5款和自定义图片均支持；原外部依据文件管理不受影响。
运行中的EXE被Windows锁定，程序文件本身的图标在正常退出后由独立助手更新，下一次打开继续使用。
更新EXE图标先校验当前程序与图标，再在副本中只修改图标资源；验证版本后原子替换，并保留原程序备份。
若程序已被新版替换或正在被占用，不覆盖新版，不影响订单；下次正常退出时可再次同步。
原程序备份和图标处理结果在本机临时目录OrderWorkbench-Icons的独立子目录中。
程序目录提供“启动订单工作台.lnk”，同目标的常用桌面/开始菜单快捷方式也会同步图标。
Windows可能缓存资源管理器图标；文件图标更新后刷新文件夹即可查看。
图标更新与软件版本更新分别校验，修改过图标的程序仍可正常安装后续正式更新。
账户、订单、风险确认、修改历史和外观设置均保留，不需要迁移。

本版新增：按登录账户记录操作
第一次打开本版时创建首个本机账户，填写账号、账户姓名和密码，原有订单不会被清空。
以后启动程序使用该账户登录；右上角显示当前账户，可点击切换。
“设置”内可添加其他账户。所有账户共用本机这份订单数据，各自修改分别留痕。
添加其他账户须先登录；切换或添加前请先保存或取消当前编辑。
密码以加盐派生值保存在data/accounts.json，不保存明文密码。请保管自己的密码。
这是本机账户系统，无需联网注册，不向GitHub上传账户、密码或订单，不会跨电脑自动同步。
复制完整data目录到其他电脑时，账户、订单、设置和记录会一并保留。仅导出订单JSON不包含账户密码。

本版新增：无料号也能确认，但必须明确确认风险
机器状态、丝印、铭牌、说明书、纸箱和采购/计划交接，可在料号为空时保存确认。
保存前弹窗列出本次涉及的机型、确认事项和缺失料号，并显示当前登录账户。
必须勾选知悉风险，再点击“知悉风险，继续保存”。取消则保留编辑，不保存本次确认。
整单办理会汇总本次新确认的缺失项，不对已保存且未变化的确认重复追加记录。
机器状态确认的风险不自动代替采购交接，包材确认的风险不自动代替计划交接。
仍须完成外形、机器状态、包材要求和网版等前置条件，本功能只允许料号后补。
风险确认不会生成或伪造料号。需向接收方说明料号待补，后续补齐并核对；交接文本附带缺料号提醒。
补齐料号或撤销相关确认会解除当前风险标记，原确认历史保留；再次产生缺失时需要重新确认。

本版新增：每个订单的“修改记录”入口
订单列表整单操作区、机型详情顶部均有“修改记录”，按整单集中查看所有机型。
记录包含实际登录账户、程序保存时间、机型、修改项目及修改前后内容，风险确认也在此查询。
新建、导入、普通编辑、整单确认、交接、归档、依据文件关联/解除和补充跟进均记录。
取消、失败和无实际变更不生成虚假的保存记录，原记录不能通过普通编辑清空或换成其他账户。
每个确认位置不重复展示账户修改历史；查看修改记录不会改写订单。
旧版历史没有账户信息时标为“旧版记录 · 未记录账户”，不会猜测或补造操作人。
记录随订单保存在data/orders.json并进入订单备份；账户文件独立保留，升级不需要迁移。

本版新增：设置与深色模式
点击左侧工具区“设置”，选择浅色、深色或跟随系统。选择后可实时预览，点“保存设置”后保留。
左上角“序”字可替换成5款内置图标之一：序、流程、交付、工作台、确认。
点击“导入图片”可使用自己的PNG、JPG、WebP、ICO；最大5MB、长宽各不超过4096像素。
图片会等比缩放为透明背景的128×128 PNG，保存在本机设置中，之后无需保留原图片。
图标设置改变工作台左上角显示，窗口、任务栏、托盘和启动快捷方式会同步，程序文件图标在正常退出后更新。
取消或按Esc会恢复已保存外观；“恢复默认外观”可预览原“序”字与浅色，保存后恢复。
未保存的设置同样会在退出程序时提示，Ctrl+S也可保存；保存失败保留编辑，多窗口冲突不覆盖。
设置独立保存在data/settings.json，上一份在data/settings.previous.json，升级继续保留。
复制完整data目录到另一台电脑后设置可继续使用；只导出订单JSON备份不包含外观设置。
深色模式覆盖概览、订单列表、看板、详情、整单确认、生产单预览、工具与设置页面。

本版新增：已有订单只补充未导入机型
拖入或选择生产单后，自动检查完整合同号及机型来源，预览中显示已导入与可补充行数。
已导入行显示“已导入”和匹配原因，包含已归档记录；复选框和字段锁定，全选不会选中这些行。
剩余行默认勾选，可继续取消不需要的行，核对后仅补入当前所选的新产品。
同合同的已有机型、确认进度、跟进历史、数量与依据路径均保持原样，不覆盖或重复创建。
识别优先使用同一生产单原行，其次核对原始序号/机型及客户型号、物料代码；改名重存或重排可继续识别。
同型号多条独立明细一对一匹配，不会因已有其中一条就把整份同型号明细全部锁定。
手工建立的机型也按同合同的型号、客户型号及可用物料代码核对；归档机型同样计入查重。
补充导入遇到原明细编号占用会分配新的唯一编号，同时保留真实来源行和序号。
全部行均已导入时按钮停用并说明原因；修改合同号会重新检查，已有数据不会改动。
如需修正已导入机型的资料或数量，请在已有机型详情修改。本功能只补入新产品，不自动覆盖旧资料。

继续保留：导入后显示所有新旧订单、临近/已过期整单计数和GitHub项目地址入口。

新增：后台自动检测更新
订单页面启动完成后约 5 秒，程序会在后台检查一次公开 GitHub 的正式版本。
持续运行时每 4 小时再检查；网络失败时不弹窗，约 30 分钟后重试，也可点击“软件更新”手动检查。
发现新版本后，左下角显示醒目的“发现新版 v版本号”。没有新版本时显示“已是最新版本”。
自动检测只检查版本资料，不会下载、安装、关闭程序或改变订单。点击更新提示后，再自行选择“下载并更新”。
后台和手动检查共用进行中的请求；近期结果可直接用于查看更新，避免重复访问。
窗口关闭后停止后台检测；不上传订单数据、文件路径或依据原文件。
已安装 v1.10 的用户，可直接通过其“软件更新”获取本版；v1.9 及更早版本请手动覆盖完整包，保留 data。

新增：软件内检查并安装更新
本版左下角提供“软件更新”。点击后会连接公开的 GitHub 仓库检查正式版本，无需登录。
发现新版本后，点击“下载并更新”。下载后先校验程序包，再检查当前工作是否已保存。
有未保存更改时，会提示“保存并更新”；保存未完成或取消核对时不会安装，也不会丢弃编辑。
准备完成后自动关闭工作台，由独立的“订单更新助手.exe”替换程序并重新打开。
订单、自动备份和外部依据文件路径均保留；只替换清单中的程序与运行组件，包内 data 不会用于覆盖。
安装中途失败会恢复已替换的原程序文件；文件被其他程序占用或无法写入时停止更新。
下载、校验或网络失败不影响继续使用；可稍后重新检查，或下载完整发行包手动覆盖。
更新暂存和旧程序备份位于本机临时目录 OrderWorkbench-Updates 的独立子目录。
换电脑后仍可直接检查更新；不需要 GitHub 凭据，也不上传订单或依据文件。

首次启用说明
v1.9 及以前没有更新入口，需要先手动安装一次 v1.10：保存并完全退出旧版，把完整包解压到原目录，保留 data 文件夹。
以后新版本发布到 GitHub Releases 后，即可通过“软件更新”安装；不会自动安装未发布的开发代码。
请保留“订单更新助手.exe”和 runtimes，不要只复制主 EXE。若程序目录只读，改放到可写的普通文件夹后再更新。

新增：生产单预览只导入需要的产品
在生产单预览左侧新增“是否导入”，默认全选。取消不需要行的勾选，该行灰显为“已排除”，不会创建订单事项。
空白或无用行被排除后，不再要求填写该行型号、数量，也不计入本次数量合计。
排除后可以重新勾选恢复；上方可“全选”“全不选”，并显示已选与已排除的行数。
核对完成后勾选确认，点击“仅导入 N 个机型”，或用 Ctrl+S 保存当前勾选的产品。
至少需要选择一行；全不选时不会创建空订单。选择范围或资料变化后，需要重新勾选核对确认。
导入编号、序号与源行仍对应原生产单，中间排除行不会让其他机型的原始要求或资料串行。
切换工作表时，当前预览中的各表选择及编辑会暂存；一次仍只导入当前工作表的勾选行。
取消预览不写入任何产品，重新打开文件需要重新核对。原生产单不会被删除或改写。
保存失败时会保留所选行和编辑；重复合同导入继续拦截，以免覆盖已有进度。
本功能用于导入前选择，已导入产品的记录仍通过原有详情功能管理。

新增：再次打开整单确认，接着上次的状态办理
已保存的机器外形、机器状态、交采购和交计划会自动显示勾选；全部机型已完成时锁定显示。
只有部分机型完成时显示横线与数量，例如“2/4 个机型已确认”，可继续勾选以办理剩余机型。
丝印、铭牌、说明书、纸箱和网版的下拉框显示所选机型已保存的实际状态。
不同机型状态不同时保持各自原状态，并在下方列出数量；选择新状态后才统一办理。
更改机型范围时，未改动的项目会跟随所选机型刷新；本次明确选择的新事项保持不变。
“重置本次事项”恢复所选机型的保存状态；“取消”放弃本次未保存的操作。
本次只保存新选择的事项，显示已有勾选不会重复交接、增加重复跟进记录或产生未保存提示。
保存成功后下次会继续保持；没有保存而取消的事项不会保留。
如需撤销已经保存的机器或交接确认，请进入对应机型的详情修改。
订单中原有状态直接可用，升级后无需重新确认。

二、整单一次关联依据文件
点击订单的“整单确认”，在“整单依据文件”区先选择流程与说明，再拖入一份或多份文件，也可选择文件或粘贴完整路径。
同一份文件的原路径会关联到本次勾选的全部机型，不必逐个拖入。可取消不适用的机型，或将不同文件分别关联到不同流程。
添加的文件先进入待关联列表；核对每个机型的变更，勾选确认，再点击“应用并保存”。也可和流程确认一起保存。
重复的同流程路径自动跳过，保留已有文件说明。取消窗口不会保存待关联文件。
整单依据区内的 Excel 只关联路径，不导入订单；窗口内其他位置会提示拖入依据区。

三、在流程旁关联依据
打开一个机型的详情，每个流程旁都有“依据文件区”：机器确认、采购交接、丝印、铭牌、说明书、纸箱、二厂网版和计划交接。
可以将文件拖入对应区域，或点击“选择文件”“粘贴路径”。一次可关联多份文件。
新增、重新关联或解除后，点击“保存更改”或 Ctrl+S，才会写入订单；退出时也会检查尚未保存的变更。
“依据文件”页按流程集中列出所有关联，还可在“其他依据”中记录额外资料。
添加依据不会自动确认流程，也不会撤销已经完成的流程。

四、拖拽入口的区别
拖到流程旁的“依据文件区”：只关联文件路径，任何类型文件都按依据处理，Excel 也不会导入订单。
拖到订单详情内的非依据区：提示你选择具体依据区，不触发生产单导入。
拖到工作台空白区：识别为生产单导入，仅接受 .xlsx，先核对预览，再确认创建机型。
依据文件拖拽和选择文件需要使用本版独立程序窗口，以便取得真实完整路径。浏览器调试模式可使用粘贴路径。

五、只保存路径，原文件留在原位置
程序保存的是路径、关联流程、说明与关联时间，不复制、移动或上传原文件，也不将其放到应用文件夹。
依据文件没有生产单导入的 8 MB 限制；每次最多关联 50 个文件，每个机型最多 200 个关联。
文件名可点击打开原文件。“定位”在文件夹中查看；“重新关联 / 说明”可更新路径、流程和说明。
“解除”只移除该机型中的关联记录，原文件保留。
记录会进入跟进历史，便于查看新增、更新或解除的时间。

六、路径变化与迁移电脑
原文件移动、重命名或共享目录未连接时，会标记“路径失效或暂不可访问”。
可点“重新检查路径”，或通过“重新关联 / 说明”选择新位置。
支持带盘符的本机完整路径和共享文件夹路径；不能只填文件名或网页地址。
备份 JSON 保存的是路径关联，不包含原文件。复制应用到另一台电脑时，需让原资料保持可访问；若路径不同，重新关联即可。
应用升级仍只替换程序文件，不需要迁移订单数据。

七、其他功能继续保留
整单批量确认、订单折叠总进度、生产单拖入核对、最近保存时间、退出保存提醒、备份及导出均继续可用。
正式订单：data\orders.json。自动备份：data\backups（最近 50 次旧版本）。
运行需 .NET Framework 4.6.2 或更新版本，以及 Microsoft Edge WebView2 Runtime。
WebView2 官方页面：https://developer.microsoft.com/microsoft-edge/webview2/
源码位于“源码”，可通过其中“编译.ps1”重新编译。第三方许可见“WebView2组件许可.txt”。
