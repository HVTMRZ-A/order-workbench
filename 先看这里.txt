订单工作台 v1.11 · 自动检测更新版

一、保留原数据升级
先保存并完全退出旧版，再把“订单工作台_v1.11_自动检测升级包.zip”解压到原“订单工作台.exe”所在文件夹，替换程序文件。
保留原来的 data 文件夹。升级包不包含 data，无需导出、导入或迁移订单。
本版保持 schema=1，旧订单没有依据文件字段也可直接读取。

新增：后台自动检测更新
订单页面启动完成后约 5 秒，程序会在后台检查一次公开 GitHub 的正式版本。
持续运行时每 4 小时再检查；网络失败时不弹窗，约 30 分钟后重试，也可点击“软件更新”手动检查。
发现新版本后，左下角显示醒目的“发现新版 v版本号”。没有新版本时显示“已是最新版本”。
自动检测只检查版本资料，不会下载、安装、关闭程序或改变订单。点击更新提示后，再自行选择“下载并更新”。
后台和手动检查共用进行中的请求；近期结果可直接用于查看更新，避免重复访问。
窗口关闭后停止后台检测；不上传订单数据、文件路径或依据原文件。
已安装 v1.10 的用户，可直接通过其“软件更新”获取本版；v1.9 及更早版本请手动覆盖完整包，保留 data。

新增：软件内检查并安装更新
本版左下角新增“软件更新”。点击后会连接公开的 GitHub 仓库检查正式版本，无需登录。
发现新版本后，点击“下载并更新”。下载后先校验程序包，再检查当前工作是否已保存。
有未保存更改时，会提示“保存并更新”；保存未完成或取消核对时不会安装，也不会丢弃编辑。
准备完成后自动关闭工作台，由独立的“订单更新助手.exe”替换程序并重新打开。
订单、自动备份和外部依据文件路径均保留；只替换清单中的程序与运行组件，包内 data 不会用于覆盖。
安装中途失败会恢复已替换的原程序文件；文件被其他程序占用或无法写入时停止更新。
下载、校验或网络失败不影响继续使用；可稍后重新检查，或下载完整发行包手动覆盖。
更新暂存和旧程序备份位于本机临时目录 OrderWorkbench-Updates 的独立子目录。
换电脑后仍可直接检查更新；不需要 GitHub 凭据，也不上传订单或依据文件。

首次启用说明
v1.9 及以前没有更新入口，需要先手动安装一次 v1.10：保存并完全退出旧版，把完整包解压到原目录，保留 data 文件夹。
以后新版本发布到 GitHub Releases 后，即可通过“软件更新”安装；不会自动安装未发布的开发代码。
请保留“订单更新助手.exe”和 runtimes，不要只复制主 EXE。若程序目录只读，改放到可写的普通文件夹后再更新。

新增：生产单预览只导入需要的产品
在生产单预览左侧新增“是否导入”，默认全选。取消不需要行的勾选，该行灰显为“已排除”，不会创建订单事项。
空白或无用行被排除后，不再要求填写该行型号、数量，也不计入本次数量合计。
排除后可以重新勾选恢复；上方可“全选”“全不选”，并显示已选与已排除的行数。
核对完成后勾选确认，点击“仅导入 N 个机型”，或用 Ctrl+S 保存当前勾选的产品。
至少需要选择一行；全不选时不会创建空订单。选择范围或资料变化后，需要重新勾选核对确认。
导入编号、序号与源行仍对应原生产单，中间排除行不会让其他机型的原始要求或资料串行。
切换工作表时，当前预览中的各表选择及编辑会暂存；一次仍只导入当前工作表的勾选行。
取消预览不写入任何产品，重新打开文件需要重新核对。原生产单不会被删除或改写。
保存失败时会保留所选行和编辑；重复合同导入继续拦截，以免覆盖已有进度。
本功能用于导入前选择，已导入产品的记录仍通过原有详情功能管理。

新增：再次打开整单确认，接着上次的状态办理
已保存的机器外形、机器状态、交采购和交计划会自动显示勾选；全部机型已完成时锁定显示。
只有部分机型完成时显示横线与数量，例如“2/4 个机型已确认”，可继续勾选以办理剩余机型。
丝印、铭牌、说明书、纸箱和网版的下拉框显示所选机型已保存的实际状态。
不同机型状态不同时保持各自原状态，并在下方列出数量；选择新状态后才统一办理。
更改机型范围时，未改动的项目会跟随所选机型刷新；本次明确选择的新事项保持不变。
“重置本次事项”恢复所选机型的保存状态；“取消”放弃本次未保存的操作。
本次只保存新选择的事项，显示已有勾选不会重复交接、增加重复跟进记录或产生未保存提示。
保存成功后下次会继续保持；没有保存而取消的事项不会保留。
如需撤销已经保存的机器或交接确认，请进入对应机型的详情修改。
订单中原有状态直接可用，升级后无需重新确认。

二、整单一次关联依据文件
点击订单的“整单确认”，在“整单依据文件”区先选择流程与说明，再拖入一份或多份文件，也可选择文件或粘贴完整路径。
同一份文件的原路径会关联到本次勾选的全部机型，不必逐个拖入。可取消不适用的机型，或将不同文件分别关联到不同流程。
添加的文件先进入待关联列表；核对每个机型的变更，勾选确认，再点击“应用并保存”。也可和流程确认一起保存。
重复的同流程路径自动跳过，保留已有文件说明。取消窗口不会保存待关联文件。
整单依据区内的 Excel 只关联路径，不导入订单；窗口内其他位置会提示拖入依据区。

三、在流程旁关联依据
打开一个机型的详情，每个流程旁都有“依据文件区”：机器确认、采购交接、丝印、铭牌、说明书、纸箱、二厂网版和计划交接。
可以将文件拖入对应区域，或点击“选择文件”“粘贴路径”。一次可关联多份文件。
新增、重新关联或解除后，点击“保存更改”或 Ctrl+S，才会写入订单；退出时也会检查尚未保存的变更。
“依据文件”页按流程集中列出所有关联，还可在“其他依据”中记录额外资料。
添加依据不会自动确认流程，也不会撤销已经完成的流程。

四、拖拽入口的区别
拖到流程旁的“依据文件区”：只关联文件路径，任何类型文件都按依据处理，Excel 也不会导入订单。
拖到订单详情内的非依据区：提示你选择具体依据区，不触发生产单导入。
拖到工作台空白区：识别为生产单导入，仅接受 .xlsx，先核对预览，再确认创建机型。
依据文件拖拽和选择文件需要使用本版独立程序窗口，以便取得真实完整路径。浏览器调试模式可使用粘贴路径。

五、只保存路径，原文件留在原位置
程序保存的是路径、关联流程、说明与关联时间，不复制、移动或上传原文件，也不将其放到应用文件夹。
依据文件没有生产单导入的 8 MB 限制；每次最多关联 50 个文件，每个机型最多 200 个关联。
文件名可点击打开原文件。“定位”在文件夹中查看；“重新关联 / 说明”可更新路径、流程和说明。
“解除”只移除该机型中的关联记录，原文件保留。
记录会进入跟进历史，便于查看新增、更新或解除的时间。

六、路径变化与迁移电脑
原文件移动、重命名或共享目录未连接时，会标记“路径失效或暂不可访问”。
可点“重新检查路径”，或通过“重新关联 / 说明”选择新位置。
支持带盘符的本机完整路径和共享文件夹路径；不能只填文件名或网页地址。
备份 JSON 保存的是路径关联，不包含原文件。复制应用到另一台电脑时，需让原资料保持可访问；若路径不同，重新关联即可。
应用升级仍只替换程序文件，不需要迁移订单数据。

七、其他功能继续保留
整单批量确认、订单折叠总进度、生产单拖入核对、最近保存时间、退出保存提醒、备份及导出均继续可用。
正式订单：data\orders.json。自动备份：data\backups（最近 50 次旧版本）。
运行需 .NET Framework 4.6.2 或更新版本，以及 Microsoft Edge WebView2 Runtime。
WebView2 官方页面：https://developer.microsoft.com/microsoft-edge/webview2/
源码位于“源码”，可通过其中“编译.ps1”重新编译。第三方许可见“WebView2组件许可.txt”。
